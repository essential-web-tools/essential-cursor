## ⚡ Instalação

### jsDelivr (recomendado)

```html
<!-- Versão fixada com SRI -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/essential-cursors@1.0.0/dist/essential-cursors.min.css"
  integrity="sha384-..." crossorigin="anonymous">
```

> **Nota:** Substitua o hash `integrity` pelo valor em [`dist/integrity.json`](dist/integrity.json).

### unpkg

```html
<link rel="stylesheet" href="https://unpkg.com/essential-cursors@1.0.0/dist/essential-cursors.min.css">
```

### npm

```bash
npm install essential-cursors
```

```css
@import 'essential-cursors';
/* ou */
@import 'essential-cursors/dist/essential-cursors.min.css';
```

## 🎯 Uso

### Modo 1: Classes utilitárias

```html
<button class="ec-pointer">Clique aqui</button>
<div class="ec-grab">Arraste</div>
```

### Modo 2: Data attributes

```html
<button data-cursor="pointer">Clique aqui</button>
<div data-cursor="grab">Arraste</div>
```

### Modo 3: Tokens CSS

```css
.my-element {
  cursor: var(--ec-zoom-in);
}
```

## 🌗 Temas

A biblioteca suporta dois temas automaticamente:

- **Tema claro** (default): halo branco ao redor dos cursores
- **Tema escuro**: halo preto ao redor dos cursores

```html
<!-- Tema escuro via data-theme -->
<html data-theme="dark">

<!-- Ou via data-cursor-theme -->
<html data-cursor-theme="dark">
```

Os cursores são trocados automaticamente via CSS custom properties.

## ♿ Acessibilidade

Essential Cursor segue as diretrizes WCAG 2.2:

- **1.4.11 Non-text Contrast**: silhueta #111111 com halo de contraste
- **2.3.3 Target Size**: área de 60×60 pixels
- **css-ui-4**: fallback keywords válidas para todos os cursores
- **prefers-reduced-motion**: sem animações por padrão
- **forced-colors**: compatível com modos de alto contraste do sistema

### Exemplo com prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  .animated-cursor {
    cursor: var(--ec-default); /* fallback estático */
  }
}
```

## 🧰 Contribuir

1. Crie/edit o SVG em `src/svg/NOME.svg` (viewBox 60×60)
2. Atualize `hotspots.json` com `[x, y, "fallback"]`
3. Rode `npm run build`
4. Rode `npm test`
5. Abra um PR

### Estrutura do hotspots.json

```json
{
  "nome-do-cursor": [x, y, "fallback-keyword"]
}
```

## 🔒 Recomendações de proteção do repositório

Para manter a segurança do supply chain:

- **Branch protection** na `main`: requer review + CI verde antes do merge
- **Tags assinadas**: use `git tag -s` para releases
- **2FA no npm**: habilite two-factor authentication para publicar
- **Dependabot**: mantenha dependências de build atualizadas
